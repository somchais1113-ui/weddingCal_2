# Wedding Fabric Studio V4 — Shape & Frame Designer

เวอร์ชันเว็บ Static แบบ **HTML ไฟล์เดียว** พร้อมใช้กับ GitHub Pages โดยตรง ไม่ต้องติดตั้ง npm, Build, CDN, backend หรือ Three.js

## เริ่มใช้งาน / อัปขึ้น GitHub

1. แตก ZIP และตรวจว่ามีไฟล์ `index.html` อยู่ในโฟลเดอร์หลัก
2. ทดลองเปิด `index.html` ใน Chrome, Safari หรือ Edge (แนะนำเบราว์เซอร์ปัจจุบัน)
3. สร้าง GitHub Repository ใหม่ หรืออัปโหลด `index.html` แทนของเดิมที่ Root ของ Repository
4. เข้า `Settings → Pages → Build and deployment` → `Deploy from a branch`, เลือก `main`, `/(root)` แล้ว Save
5. หลัง Deploy รอ GitHub เผยแพร่ และกด Hard Reload (Mac: `Command + Shift + R`)
6. ถ้ามีปัญหา ให้นำ URL และภาพ Console จาก Developer Tools มาใช้ตรวจสอบ อย่าปรับ Workflow แบบสุ่ม

> ไม่ต้องอัปโหลดไฟล์ใน `tests` หรือเอกสาร README ก็เปิดเว็บได้ `index.html` เพียงไฟล์เดียวพอ

## ฟีเจอร์หลัก

- Backdrop Drape / Ceiling Drape พร้อมสูตรจากบรีฟเดิม
- หลาย Layer, ปรับขนาด, สี, ความทึบ, แนวซ้อน, ราคาเมตร, จำนวนชุด และ Export CSV / JSON / PNG
- อัปโหลดภาพอ้างอิง แล้วตีกรอบเพื่อประเมินมิติ 2D **ต้องมีขนาดจริงอ้างอิงที่ผู้ใช้กรอก** ไม่ใช่ระบบอ่านขนาด 3D จากภาพอัตโนมัติ
- **Move Layer**: เลือก Layer → กดปุ่มทิศทาง (ซ้าย ขวา ขึ้น ลง), ปรับ Step หน่วยซม., หรือเลือก **Move Layer** บน Preview แล้วลากภาพ; สลับ **Orbit** เพื่อหมุนกล้อง; ปุ่มลูกศรคีย์บอร์ดทำงานเมื่อโฟกัสที่ Canvas
- **Curve** สำหรับ Backdrop: Straight, Arch, Scallop, Wave, Diagonal; ปรับ Depth, Repeats, Sweep โดยแยกแต่ละ Layer
- **Steel Frame Preliminary Screening**: วาดผังเสา/คาน, เลือกตัวอย่างหน้าตัด SHS/RHS, กรอกระยะเสา, GSM, อุปกรณ์, ราคาต่อเหล็กยาว 6 ม.; ประเมินน้ำหนักผ้าและคานจากแรงโน้มถ่วงเท่านั้น

## วิธีคิดปริมาณผ้า

### Backdrop แบบตรง

```
panelCount = ceil(backdropWidth × fullnessRatio / fabricWidth)
theoreticalLengthCm = panelCount × backdropHeightCm
```

### Backdrop แบบ Curve

สำหรับแต่ละผืน ระบบหาความยาวมากสุดของแนวผ้าหลายตำแหน่งตามเส้นโค้งขอบล่าง แล้วรวมความยาวของผืนตามนั้น โดยเผื่อการส่ายแนวผ้า (Sweep) ผ่านการประมาณ Arc Length ของเส้นกึ่งกลางแนวตั้ง 64 ช่วง ตัวเลขนี้เป็น **cut-length estimate เชิงอนุรักษ์** ไม่ใช่ Cutting Pattern ตามสเกลพร้อมตัดจริง ระบบไม่จำลองการยืดตัว การเย็บแบบ bias สายรูด องศาทิ้งตัว หรือรูปแบบการตัดผ้าที่ซ้อนชิ้นงานได้

### Ceiling Drape

- แบบตามบรีฟ: `spanDistance × [1 + (sagDepth / spanDistance) × 0.6] × numberOfSwags`
- ทางเลือก Exact Catenary: ความยาวเส้นโค้งของสายแขวนปลายระดับเท่ากัน โดยแก้หา parameter `a` ทางตัวเลข
- การคำนวณเพดานสมมติว่า 1 ช่วงใช้ผ้า 1 ความกว้างหน้า เนื่องจากยังไม่มีโมดูลต่อหน้าผ้าสำหรับผืนที่กว้างกว่า 1 หน้าผ้า

### ส่วนเผื่อและยอดซื้อ

```
recommendedMeters = theoreticalMeters × (1 + totalBufferPercent / 100)
purchaseMeters = roundUp(recommendedMeters × quantity, purchaseIncrement)
fabricCost = purchaseMeters × pricePerMeter
```

ส่วนเผื่อ 4 ชนิด: ตะเข็บ, หด, จับลาย, เสียหายหน้างาน โดยไม่บวกค่าตะเข็บซ้ำในสูตรทฤษฎี และปัดแยกแต่ละ Layer

## โครงเหล็ก — สมมติฐานและสิ่งที่ *ไม่* รับรอง

> **ไม่ใช่เครื่องมือออกแบบวิศวกรรมหรือใบรับรองความปลอดภัย** ห้ามใช้ค่า stress/deflection เพียงอย่างเดียวตัดสินว่าคานและเสารับน้ำหนักได้ โดยเฉพาะงานกลางแจ้ง งานเหนือศีรษะ และงานที่มีแขกร่วมงาน

ค่าที่แสดงคำนวณจาก:

- น้ำหนักผ้าประมาณ = `theoreticalLength (m) × fabricWidth (m) × GSM / 1000`
- น้ำหนักต่อช่วง = `(fabricWeight + accessoriesWeight) / bayCount + beamSelfWeight`
- คานรองรับแบบ Simply Supported และโหลดสม่ำเสมอ: `Mmax = w L² / 8`
- `sigma = Mmax × c / I`; `delta = 5 w L⁴ / (384 E I)` โดยตั้ง `E = 200,000 N/mm²` สำหรับตัวอย่างคำนวณเหล็ก
- หน้าตัด SHS/RHS คิดแบบท่อเหลี่ยมกลวงทรงเรขาคณิตอุดมคติ (ไม่คิดมุมโค้ง ความคลาดเคลื่อนโรงงาน สนิมหรือรูเจาะ)
- ตัดจำนวนเหล็กยาว 6 เมตรแบบ First-Fit-Decreasing แยกกลุ่มคานและเสา ยังไม่คิดความกว้างรอยตัด/ต่อท่อ/ค้ำยัน
- ค่าเหล็กต่อเส้นที่กรอกเป็นค่าที่ผู้ใช้สมมติ ไม่ใช่ราคาอ้างอิงร้านค้า
- รวมเงินค่าเหล็ก *แสดงแยก* และยังไม่ถูกรวมในยอดผ้า + ค่าแรง

**ยังไม่ได้คำนวณ:** แรงลม แรงดูด/แรงดึงผ้า ปริมาณลมจากช่องเปิด โหลดเฉพาะจุด การกระแทก การเยื้องศูนย์ ค้ำยัน สลิง โซ่ เพลา/พุก/สมอ ฐานเหล็ก/ฐานคอนกรีต เสถียรภาพเสาตั้ง จุดเชื่อม รอยเชื่อม การโก่งเดาะ คานบิดตัว ความแข็งแรงเหล็กจริง ตลอดจนประเมินสภาพพื้นจริงและแนวแรงลม

**รายการชิ้นส่วนที่ควรมีในแบบก่อสร้างจริง:** คานบน, เสา, ค้ำยันแนวทแยง, ข้อต่อและเพลทต่อ, เพลทฐาน, พุก/สมอ/บล็อกถ่วง, แขวนผ้า/ราง/สลิง, safety retention และรายละเอียดงานเชื่อม/สลักเกลียว **ขนาดและจำนวนชิ้นส่วนเหล่านี้ต้องระบุหลังวิศวกรออกแบบ**

### ข้อมูลสำหรับให้วิศวกรตรวจจริง

รูปด้าน/รูปตัดพร้อมความกว้าง-สูง-ลึกทุกช่วง, ผังเสาและระบบค้ำยัน, สถานที่ในร่ม/กลางแจ้ง, พื้นผิว/จุดฝังหรือถ่วง, ลักษณะผ้า/ความพรุน, น้ำหนักอุปกรณ์แสงเสียง, รูปแบบการยึดและเชื่อม, ความเสี่ยงจากแรงลม, ระยะทางหนีไฟและจำนวนผู้เข้าร่วม

อ่านหลักการงานโครงสร้างชั่วคราวเพิ่มเติม: [Institution of Structural Engineers — Procurement and use of demountable structures](https://www.istructe.org/resources/guidance/procurement-and-use-of-demountable-structures/), [MUTA Best Practice Guide](https://www.muta.org.uk/best-practice-guide/)
