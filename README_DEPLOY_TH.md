# Wedding Fabric Studio V5

## วิธีใช้งานแบบง่าย
1. ใช้ไฟล์ `index.html` เพียงไฟล์เดียว
2. อัปโหลดขึ้น GitHub Pages ได้ตรง ๆ ที่ root ของ repository
3. เปิดเว็บแล้วเลือก preset รูปแบบฉากเพื่อเริ่มต้นเร็ว
4. ตรวจขนาดจริงและรายการตัดเหล็ก 6 ม./เส้น ก่อนสั่งซื้อ

## ของใหม่ใน V5
- Preset รูปแบบฉากจากภาพอ้างอิง
- Render สมจริงขึ้น พร้อมคนอ้างอิงสเกล
- คำนวณเหล็ก 6 ม./เส้น แยกคาน เสา ค้ำยัน และเพลทฐาน
- ยังเป็นเครื่องมือประมาณการเบื้องต้น ไม่ใช่งานออกแบบโครงสร้างที่ผ่านการรับรอง
