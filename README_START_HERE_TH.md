# Wedding Fabric Studio V3 — Layer Designer & Cost Calculator

เว็บแอป **Static / No Build** สำหรับออกแบบผ้าหลายชั้น ประเมินปริมาณผ้าตามขนาดจริง ประเมินต้นทุน และตีกรอบภาพอ้างอิงโดยกำหนดสเกลเอง

## เปิดบน GitHub Pages (ไม่ต้อง npm, ไม่ต้อง GitHub Actions)

1. สร้าง Repository ใหม่ที่ GitHub เช่น `wedding-fabric-studio-v3` และตั้งค่าการมองเห็นเป็น Public (หรือตามเงื่อนไขบัญชี)
2. แตก ZIP จากนั้น **อัปโหลดเนื้อหาด้านในทั้งหมด** เข้าราก (root) ของ Repository: `index.html`, `assets/`, `.nojekyll`, เอกสาร ฯลฯ **อย่าอัปโหลด ZIP เป็นไฟล์เดี่ยว** และอย่าให้มีโฟลเดอร์ครอบอีกชั้น
3. ไปที่ `Settings → Pages → Build and deployment` เลือก **Deploy from a branch**, Branch `main`, Folder `/(root)` แล้ว Save
4. รอ Workflow Pages แสดงผล Deploy สำเร็จ เว็บไซต์จะอยู่ที่ `https://USERNAME.github.io/wedding-fabric-studio-v3/`
5. เมื่อเว็บเปิดแล้ว ตรวจแท็บ Network ของ Browser ว่า `assets/app.js`, `assets/project.js`, `assets/engine.js`, `assets/renderer.js`, `assets/style.css` ตอบกลับ 200

เว็บใช้ Relative URLs (`./assets/...`) จึงรองรับ URL ของ GitHub Pages ภายใต้ชื่อ Repository ต่างกันโดยไม่ต้องแก้ Vite `base`.

## วิธีใช้งาน

1. เลือก **ฉากผ้า** หรือ **ผ้าหย่อนเพดาน**
2. เลือก Layer ในรายการด้านล่าง แล้วแก้ขนาด ผ้า ความฟู ราคาต่อเมตร จำนวนชุด สี ความทึบ ระยะซ้อน และตำแหน่ง
3. กด **เพิ่ม Layer** หรือ **ทำสำเนา** เพื่อสร้างชั้นผ้าใหม่ได้สูงสุด 12 ชั้น; ลูกศรเปลี่ยนลำดับเรนเดอร์
4. เปิดแท็บ **ภาพอ้างอิง** อัปโหลด JPG / PNG / WEBP (สูงสุด 12 MB) กรอก **กว้างและสูงจริงของระนาบในภาพ** แล้วลากกรอบรอบพื้นที่ผ้า หรือทดลองคลิกด้วยโหมด **เลือกจากสี**
5. กด **ใช้ขนาดนี้กับ Layer** ระบบแปลงสัดส่วนภาพเป็นเซนติเมตร และคำนวณใหม่ทันที
6. กำหนดส่วนเผื่อเย็บ / หด / จับลาย / ความผิดพลาด แล้วตรวจยอดสั่งซื้อแยก Layer
7. ตั้งราคาต่อเมตร ค่าแรง อุปกรณ์ และ Export CSV หรือ Project JSON; ส่งออกพรีวิว 3D เป็น PNG ได้

> **จำกัดสำคัญของการประเมินจากภาพ**: เป็นการประมวลผลเรขาคณิต 2D + การค้นหากลุ่มสีต่อเนื่องอย่างง่าย (ไม่ใช่ AI segmentation / photogrammetry) ต้องกรอกขนาดอ้างอิงจริงในระนาบเดียวกับผ้า หากถ่ายเฉียงหรือมีมุม Perspective ขนาดจะคลาดเคลื่อน ระบบจะไม่เดาระยะลึก ความโค้งผ้าหรือขนาดจริงจากภาพภาพเดียว ควรตรวจด้วยตลับเมตรหรือ Drawing ก่อนสั่งซื้อ

## สูตรและหลักการต้นทุน

- ฉากผ้า: จำนวนผืน `ceil(กว้างจริง × ความฟู / หน้าผ้า)`; ปริมาณทฤษฎี `จำนวนผืน × สูงจริง` (cm)
- เพดาน: ความยาวต่อช่วง = `span × (1 + sag/span × 0.6)` ตามสูตรประมาณในบรีฟ หรือ `catenary` จริง (ตามตัวเลือก); คูณจำนวนช่วง
- ส่วนเผื่อรวม = เผื่อเย็บ + เผื่อหด + เผื่อจับลาย + เผื่อเสียหาย (ปรับได้)
- **คิดเผื่อเพียงครั้งเดียว**: ทฤษฎี × (1 + เผื่อรวม/100)
- หากทำซ้ำหลายชุด: ปริมาณหลังเผื่อ × จำนวนชุด แล้วปัดขึ้นตามหน่วยสั่งซื้อใน **แต่ละ Layer**
- ผ้าต่อ Layer (บาท) = เมตรสั่งซื้อที่ปัดแล้ว × ราคาต่อเมตร; รวมผ้า = ผลรวมต้นทุนแต่ละ Layer; รวมโครงการ = รวมผ้า + ค่าแรง + อุปกรณ์
- การซ่อน Layer (ไอคอนวงกลม) **ซ่อนจากพรีวิวเท่านั้น** ไม่ลดรายการสั่งซื้อ หากไม่ต้องการใช้ให้ลบ Layer
- ระวังว่าผ้าต่างหน้ากว้าง/ราคา/ชนิดไม่ควรเอายอดเมตรไปรวมสั่งซื้อเป็นโรลเดียวกัน ต้องแยกตามรายการ BOM; หากเป็นวัสดุเดียวกัน อาจต้องวางแผนแพตเทิร์นก่อนรวมยอดสั่งจริง

## บันทึกข้อมูล

- แบบร่างปัจจุบันจะถูกเก็บใน `localStorage` ของเบราว์เซอร์เดียวกัน โดย **ไม่เก็บภาพอ้างอิงใน localStorage** เพื่อไม่ให้พื้นที่เต็ม
- ดาวน์โหลด **Project JSON** เพื่อเก็บ Layer และภาพอ้างอิงที่บีบอัดรวมไว้ในไฟล์ แล้ว Import คืนได้
- ไม่มีการส่งไฟล์ภาพ/ข้อมูลโปรเจกต์ไปยังเซิร์ฟเวอร์; แอปใช้งานแบบ Client-Side
- Export CSV ใช้ UTF-8 พร้อม BOM เพื่อเพิ่มความเข้ากันได้กับ Excel ภาษาไทย

## ทดสอบโดยไม่ติดตั้งแพ็กเกจ

ต้องมี Node.js 20 ขึ้นไป:

```bash
node --test tests/core.test.mjs
```

วิธีเปิดบนเครื่องคอมพิวเตอร์ (ไฟล์ JavaScript เป็น ES Module ต้องใช้ localhost แทน double-click `index.html`):

```bash
python3 -m http.server 8080
```

เปิด `http://localhost:8080` และทดสอบบน Desktop และ Mobile ได้
