# Wedding Fabric Studio V6 — RC1

เครื่องมือถอดแบบฉากผ้าจากภาพอ้างอิง แก้รูปทรง และจัดทำรายการผ้า/เหล็ก

**สถานะส่งมอบ:** Source และ Static Build สร้างแล้ว, Automated Tests ของแกนระบบผ่านจริง อ่านจำนวนและหลักฐานใน `QA_REPORT_TH.md` ส่วน Browser Acceptance ยังถูกบล็อกเพราะสภาพแวดล้อมไม่มี Chromium ที่พร้อมรัน **ยังไม่ถือว่าผ่าน Acceptance ทั้งหมด และยังไม่มี Screenshot จากเบราว์เซอร์หรือ URL ที่ Deploy แล้ว**

## เปิดใช้งานบนเครื่อง

ต้องมี Node.js 20.11 ขึ้นไป (แนะนำ 22 หรือใหม่กว่า)

```bash
npm test
npm run build
npm run dev
```

เปิด `http://127.0.0.1:4173/` แอปไม่มี runtime dependency หรือ CDN ไม่ต้อง `npm install` เพื่อ Build/รันตัวแอป แต่ไม่ควรเปิด `index.html` ด้วย `file://` เพราะใช้ ES Modules และการอ่านไฟล์ตัวอย่าง

ติดตั้งเฉพาะเมื่อจะรัน Browser Tests:

```bash
npm install
npx playwright install chromium
npm run test:browser
```

บน Linux ที่ไม่มี dependency ของ Chromium ใช้ `npx playwright install --with-deps chromium` ตามสิทธิ์ของเครื่องนั้น

## เริ่มจากภาพอ้างอิง

1. เปิด “ถอดแบบภาพ” และเลือก JPG / PNG / WEBP ไม่เกิน 16 MB ระบบย่อด้านยาวเป็นไม่เกิน 1,800 px เพื่อเก็บในโปรเจกต์
2. กรอกความกว้าง/สูงจริงของ **ระนาบฉากเดียวกัน** หน่วยเซนติเมตร
3. เลือก 4 มุมตามลำดับ: ซ้ายบน → ขวาบน → ขวาล่าง → ซ้ายล่าง ลากจุดเพื่อปรับได้ แล้วกด “ปรับ Perspective”
4. กด “สร้างชั้นจาก Trace” จะได้ขอบบนและขอบล่างเริ่มต้น ลากให้ทับขอบผ้าในภาพ
5. เลือกจุดเพื่อแก้ Bézier Handle (สี่เหลี่ยม), เพิ่ม Anchor หรือระบุบทบาท แขวน/ผูก/รวบ/ปล่อย ด้านซ้าย
6. ใช้ “เทียบภาพ” ดูภาพปรับมุมพร้อมเส้น Trace และ Mesh ในมุมหน้า ปรับ Z, ความนูนลึก, สี, Fullness และวัสดุตามข้อมูลหน้างาน
7. ตรวจ BOM และแผนตัดก่อน Export; เก็บ JSON เพื่อเปิดงานและ Anchor เดิมต่อ

**ไม่มี AI ตรวจภาพอัตโนมัติใน RC1** การ Trace และ Calibration เป็นข้อมูลที่ผู้ใช้ระบุ; ความลึกเป็นค่าที่กำหนดเอง; Mesh และปริมาณวัสดุเป็นค่าประมาณ ระบบไม่อ้างว่ารู้ขนาดจริงจากภาพถ่ายเพียงอย่างเดียว

## เครื่องมือออกแบบ

- Straight, Swag, Scallop, Arch, Cross Drape, Side Sweep, Center Tie และ Trace
- Cross Drape เป็นผ้าพาดเฉียงหนึ่งชั้น เลือกทิศลงซ้าย/ขวา ทำสำเนาอีกชั้นและปรับ Z เพื่อสร้างคู่ไขว้
- ผ้าเพดาน: จำนวนช่วง/ระยะหย่อน, สูตรประมาณเดิมหรือ Catenary ปลายระดับเท่ากัน
- Preview: หมุน, เลื่อน, Zoom, มุมหน้า/ข้าง/บน/Perspective; ย้าย Layer ด้วยการลากในมุมหน้า
- คลิกผ้าเลือก Layer; ปุ่มลูกศรย้าย 1 ซม., Shift+ลูกศร 10 ซม.
- ปรับสี ความทึบ ความด้าน ความโปร่ง, คนอ้างอิง 170 ซม. และความสูงคน
- Clean / Soft / Presentation ใช้แสงนุ่ม ไม่มีเงาดำตกพื้น
- Front/Middle/Back เป็นกลุ่มจัดวางและค่า Z ตั้งต้น ระยะ Z ของแต่ละ Layer แก้เองได้
- ซ่อน/ล็อก/ทำสำเนา/เลื่อนลำดับ; การซ่อน **ยังนับใน BOM**; Quantity คิดจำนวนชุดใน BOM ส่วน Preview แสดงหนึ่งชุด
- Undo/Redo ได้จากปุ่ม หรือ Ctrl/⌘+Z และ Ctrl/⌘+Shift+Z (ไม่แย่ง Undo ขณะพิมพ์ในช่อง)

## วิธีประมาณผ้า V6

หน่วยเรขาคณิตทั้งหมดเป็น **ซม.**; ผลสั่งซื้อเป็น **เมตร**

1. คำนวณความกว้างตามผิวโค้งจากแนวขวางหลายตำแหน่ง ไม่ใช้ความยาวเส้นขอบบนจอแทนผ้าทั้งผืน
2. หน้าผ้าใช้ได้ = หน้าผ้าม้วน − ตะเข็บข้าง 2 ด้าน
3. จำนวน Panel = ปัดขึ้น (ความกว้างตามผิวสูงสุด × Fullness ÷ หน้าผ้าใช้ได้)
4. ต่อ Panel ใช้ความยาวตามผิวแนวยาวสูงสุดจากการสุ่มตัวอย่างในช่วงนั้น เป็นซองตัดแถบสี่เหลี่ยม; ไม่คลี่ Mesh เป็นแพทเทิร์นสมบูรณ์
5. ต่อผืน: บวกเผื่อหัว/ท้าย → หาร `(1−อัตราหดตัว)` → ปัดขึ้นตามระยะซ้ำลาย
6. รวมทุกผืน × จำนวนชุด → บวกเผื่อเสีย → ปัดยอดสั่งซื้อแยก Layer
7. ราคา = ยอดสั่งซื้อ × ราคาต่อเมตร

ค่าทฤษฎีในตารางคือความยาวรวมของแถบก่อนเผื่อ ไม่ใช่ความยาวขั้นต่ำที่พิสูจน์แล้ว ค่าความโปร่ง/ความด้านไม่เปลี่ยนการสั่งผ้า ส่วน Fullness และรูปทรงมีผลกับวัสดุจริงในสูตร

ดู `docs/CALCULATION_METHOD_TH.md` สำหรับข้อสมมติและตัวอย่างตรวจด้วยมือ

## โครงเหล็ก

เพิ่มรายการ SHS, RHS, ROUND (เหล็กตันกลม), SOLID (เหล็กตันสี่เหลี่ยม) ระบุหน้าตัด/ความหนา/เกรด/ความยาว/จำนวน/ราคาต่อเส้น กรอกเพลทและอุปกรณ์แยกชิ้นได้

- สต็อก 6,000 มม.; หน้าตัด/เกรดต่างกันแยกกลุ่ม
- Best-fit decreasing พร้อม Kerf ต่อชิ้น; แสดงแต่ละเส้นและเศษจริง
- ถ้าชิ้นยาวเกิน 6 เมตร หรือยาวรวม Kerf ไม่พอ จะเตือนและตัดออกจากยอด พร้อมแจ้งว่ายอดยังไม่ครบ ไม่มีการสมมติต่อเหล็ก
- “จำนวนเส้นเท่าขอบเขตต่ำสุด” แสดงเฉพาะเมื่อจำนวนเส้นเท่ากับ lower bound ที่คำนวณได้; กรณีอื่นไม่รับรอง global optimum
- น้ำหนักเป็นค่าหน้าตัดอุดมคติ ไม่ยืนยันความปลอดภัยของโครงสร้าง

## บันทึกและ Export

- บันทึกในเครื่องด้วย IndexedDB รวมภาพและ Anchor; ข้อมูลแยกตาม origin/เบราว์เซอร์ ไม่ Sync ข้ามเครื่อง
- บันทึก JSON เพื่อสำรอง/โอนงาน; Private Mode, ล้างข้อมูลเว็บ หรือ Storage Quota อาจทำให้แบบร่างหาย
- BOM CSV รวมผ้า, ความยาวตัดราย Panel, เหล็ก, อุปกรณ์, ค่าแรงและค่าใช้จ่ายอื่น
- Cut List CSV แยกต่อเส้นพร้อม Kerf/เศษ; เปิดด้วย Excel ได้ (UTF-8 BOM)
- Preview PNG ของ viewport ปัจจุบัน (ในหน้าเทียบภาพ Export เฉพาะ 3D)

## ความเข้ากันได้ V5

- `legacy/` เก็บ V5 ทั้งชุดโดยไม่แก้ไข
- นำเข้า JSON รูปแบบ layer-based ของ V3–V5 และแบบร่างเดิมจาก localStorage origin เดียวกัน
- ชั้นที่นำเข้าใช้ `estimateMode: legacy` เก็บสูตรและเปอร์เซ็นต์เผื่อเดิม ไม่เปลี่ยนยอดเงียบ ๆ
- แก้ชื่อ/ขนาด/สี/ราคาได้; เปลี่ยนเป็นแผนตัด V6 ด้วยตัวเลือก “วิธีประมาณวัสดุ” เมื่อพร้อมยืนยันสูตรใหม่
- Presets เดิมทั้ง 7 ชุดอยู่ในเมนูรูปแบบ; การเลือก preset แทนโปรเจกต์ปัจจุบัน แต่ย้อนกลับได้
- V6 ใช้ตำแหน่ง Y ลงจากขอบบน ไม่ใช่ Y ขึ้นจากพื้นเหมือน V5 การแปลงรักษาตำแหน่งฉากตั้งโดยประมาณ; รูปทรง/กล้องไม่รับรอง pixel-identical
